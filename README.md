I build open-source infrastructure and enjoy solving problems that make complex systems work better together.

My work spans distributed systems, cloud platforms, blockchain, digital identity, and verifiable data. I'm particularly interested in open technologies that make systems more dependable, interoperable, and accessible.

### What I'm building

**[Commons](https://commons.tech/)**

Making it easier to collect, share, and keep data in sync across organizations and ecosystems. Commons takes a local-first approach, giving participants control over their data while keeping shared information current, verifiable and accessible.

**[Dhiway](https://www.dhiway.com/)**

Building open infrastructure for digital trust and verifiable data. Our work includes [CORD](https://github.com/dhiway/cord), a Substrate-based blockchain framework, along with developer tools and libraries for decentralized applications.

### Along the way

### What I'm building

**[Commons](https://commons.tech/)**

Useful data is scattered across systems, organizations, and ecosystems. Collecting it, keeping it current and making it available where it's needed often involves more work than it should.

We're building Commons to change that.

Commons is a local-first approach to data coordination. It lets participants collect, publish, and subscribe to data while keeping their own copies in environments they control. Updates sync between participants, changes can be verified, and version history remains available so you can understand how information has evolved.

The interesting engineering challenges lie in making this work across different systems, devices, and organizational boundaries without requiring everyone to adopt the same infrastructure.

Under the hood, we use content-addressed storage, peer-to-peer synchronization, distributed discovery, data provenance, and open protocols.

**[Dhiway](https://www.dhiway.com/)**

At Dhiway, we've been building open infrastructure for digital trust, verifiable records and decentralized systems.

Our work includes [CORD](https://github.com/dhiway/cord), a blockchain framework built on Substrate, along with developer libraries, identity infrastructure and tools that help applications work with verifiable information.

Much of what we've learned about trust, interoperability, and distributed infrastructure still influences the systems we're building today.
